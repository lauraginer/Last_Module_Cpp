Aqui aparece las funciones/clases templates y por cabezonería mia, los vectores. 

Un vector es un array dinámico que crece automáticamente.
Diferencias con array normal:

				Array						Vector
Tamaño			Fijo (en compilación)		Dinámico (en runtime)
Memoria			Stack						Heap
Redimensión		No							Sí (automático)

Cómo declarar:

#include <vector>

std::vector<int> v;              // vacío
std::vector<int> v(5);           // 5 elementos (inicializados a 0)
std::vector<int> v = {1, 2, 3}; // inicializado con valores


Operaciones básicas:

std::vector<int> v;

v.push_back(10);     // añade al final
v.pop_back();        // elimina último
v.size();            // número de elementos
v[0];                // acceso por índice (como array)
v.at(0);             // acceso seguro (lanza excepción si fuera de rango)
